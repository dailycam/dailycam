# DailyCam 메뉴 구조

## 랜딩 페이지 (비로그인)
홈 (/): 서비스 소개, 주요 기능 안내, 회원가입/로그인 유도

## 인증
로그인 (/login): Google OAuth 2.0 소셜 로그인, JWT 토큰 기반 인증
회원가입: Google 계정으로 자동 가입
인증 콜백 (/auth/callback): OAuth 인증 후 리다이렉트 처리

## 메인 앱 (로그인 후)

### 공통 접근 가능 (구독 여부 무관)
프로필 설정 (/profile-setup): 아이 정보 등록 (이름, 생년월일 등)
구독 관리 (/subscription): 베이직/프리미엄 플랜 선택 및 결제 (PortOne 연동)
설정 (/settings): 계정 정보, 카메라 설정, 알림 설정

### 구독자 전용 기능 (보호된 라우트)

홈 (/home): 
  - 오늘의 하이라이트 영상
  - AI 육아 팁 추천
  - 빠른 시작 (카메라 연결, 실시간 모니터링)
  - 인기 콘텐츠 및 블로그 추천

대시보드 (/dashboard):
  - 오늘의 종합 요약 (안전 점수, 발달 점수)
  - 시간대별 활동 히트맵
  - 24시간 안전 상태 시계형 차트
  - 주요 이벤트 타임라인
  - 활동 카테고리별 통계

실시간 모니터링 (/monitoring):
  - HLS 실시간 영상 스트리밍
  - 현재 활동 인식 결과 표시
  - 안전 점수 실시간 업데이트
  - 카메라 전환 (다중 카메라 지원 시)

발달 리포트 (/development-report):
  - 5개 영역 발달 레이더 차트 (신체, 인지, 언어, 사회성, 정서)
  - 월령별 발달 추이 그래프
  - 발달 단계별 추천 활동
  - 일일/주간/월간 발달 요약

안전 리포트 (/safety-report):
  - 안전 점수 트렌드 차트
  - 위험 요소 카테고리별 분석 (낙상, 질식, 감전 등)
  - 시간대별 안전 이벤트 로그
  - 안전 개선 제안 및 육아 팁

클립 하이라이트 (/clip-highlights):
  - AI가 자동 생성한 중요 순간 클립
  - 날짜별/카테고리별 필터링
  - 클립 다운로드 및 공유
  - 즐겨찾기 관리

비디오 분석 테스트 (/video-analysis-test):
  - 영상 업로드 및 수동 분석 요청
  - AI 분석 결과 즉시 확인
  - 테스트 및 디버깅 용도

## 사이드바 구성 요소

로고 및 브랜드: Daily-cam 로고, "아이 곁에" 슬로건

메인 네비게이션:
  - 홈
  - 대시보드
  - 모니터링
  - 발달 리포트
  - 안전 리포트
  - 클립 하이라이트
  - 비디오 분석
  - 설정

구독 정보 (하단):
  - 구독 중: 플랜명, 남은 기간, 진행 바, "플랜 관리" 링크
  - 미구독: "프리미엄 기능을 이용하려면", "구독하기" 버튼

## 주요 기능별 설명

### 실시간 분석 파이프라인
카메라 → Nginx RTMP → HLS 변환 → 10초 세그먼트 → AI Worker → Gemini API → 분석 결과 저장 → 대시보드 표시

### 자동 집계 시스템
10분 단위 분석 → 1시간 집계 → 일일 리포트 자동 생성

### 하이라이트 클립 생성
AI가 중요도 점수 기반으로 자동 선별 → 클립 생성 → 썸네일 추출 → 사용자에게 제공

### 발달 평가 시스템
영상 분석 → 5개 영역 점수 계산 → 레이더 차트 시각화 → 월령별 비교 → 맞춤 활동 추천
